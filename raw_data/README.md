# Raw source retention

This directory intentionally contains no inherited BetterLB/Los Baños exports. The original raw exports were removed from the Santa Cruz working tree because publishing them would risk misattribution.

Retain a source snapshot here only when it is public, legally and technically appropriate to archive, and useful for replay or audit. Keep the original filename, source URL, retrieval timestamp, and optional SHA-256 checksum in the source registry or an adjacent manifest. Never edit an archival snapshot in place.

Blocked pages, volatile search indexes, and sources that do not need local replay remain represented by registry metadata. Normalized data belongs under `src/data/`, and only after review.
