# Code of Conduct

BetterSantaCruz is a community-run civic technology project. We welcome good-faith participation from residents, researchers, maintainers, and public-interest contributors.

Participants are expected to:

- treat others with respect and patience;
- discuss evidence and implementation rather than attack people;
- credit public sources and other maintainers;
- protect private information and unpublished correspondence;
- respect requests to stop contact or collaboration;
- avoid impersonation, harassment, discrimination, doxxing, and misleading civic claims.

Report a concern through the repository's private GitHub reporting mechanism when available. Do not include passwords, tokens, private phone numbers, or other sensitive information in public issues.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/3/0/).
