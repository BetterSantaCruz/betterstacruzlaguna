# Pagsanjan research boundary

This directory preserves public research and collaboration context about Pagsanjan, Laguna that was collected while BetterSantaCruz was being bootstrapped.

It is **not** part of BetterSantaCruz's production source registry and must not be imported by the public Santa Cruz application, civic-data validator, search index, or publication pipeline.

An existing BetterPagsanjan project and maintainer already exist. These records are retained only for research handoff/collaboration context; they do not establish BetterSantaCruz ownership or authority over Pagsanjan data.
