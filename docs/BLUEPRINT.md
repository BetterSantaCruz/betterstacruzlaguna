# BetterSantaCruz blueprint

## Product promise

Help a resident find trustworthy local information quickly, while showing exactly what is known, what was observed, and what still needs verification. BetterSantaCruz is an independent community project and must not look like a municipal campaign or official LGU site.

## First release

- Home: resident task search, project status, disclaimer, source-ledger entry point.
- Sources: searchable/readable source inventory with verification states and last-checked dates.
- About/contribute: governance, correction path, and privacy boundaries.
- Existing BetterLB modules remain available as architecture but are feature-gated or empty until data passes review.

## Deferred until evidence exists

Government directory, barangays, Citizens' Charter, legislation, finance, procurement, infrastructure, tourism, statistics, weather/map, Meilisearch, D1 writes, admin mutation, and external deployment.

## Success gates

1. No Los Baños factual payload or branding can be rendered as Santa Cruz.
2. Every civic fact has machine-readable provenance.
3. Same-name municipality filters require province/region or an agency identifier.
4. Empty states explain the gap and link to the relevant source lead.
5. Tests, lint, typecheck, build, and a browser smoke/a11y pass are green before publication.
